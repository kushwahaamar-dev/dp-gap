## Results (Current)

All drafts use **actual experiment results** from **Mistral 7B (Ollama)** and **Qwen 2.5 7B (Ollama)**.
Primary numbers and figures are from Mistral 7B (900 data points per model).
Figures in each `*/results/` directory are generated by `python -m src.analysis --input results/<model>/experiment_results.csv --output-dir results/<model>`.
